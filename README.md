# 출튀 대작전 · Campus Escape

교수님의 시선을 피해 출석하고 강의실을 탈출하는 한국어 웹 잠입 게임입니다. 키보드와 모바일 터치 조작, 10개 스테이지, 서버가 입력을 재생해 검증하는 단계별 온라인 순위표를 제공합니다.

**[온라인 플레이](https://campus-escape-oct27.pimanglee.chatgpt.site)**

## 플레이

- 방향키 / WASD: 이동
- SPACE: 책상 근처에서 숨기
- E 길게 누르기: 출석, 가방, 수색, 잠금 해제, 문 열기
- P: 일시정지
- 5단계부터는 시야에 잡히면 의심이 지속됩니다. 초록색 책상 앞자리로 복귀하면 추적이 풀리고 의심도가 초당 20% 감소합니다.
- 행동 중 시야에 들어오거나 교수의 붉은 근접 범위에 들어가면 즉시 실패합니다.

| 단계 | 주요 규칙 |
|---|---|
| 1 | 출석 후 탈출 |
| 2 | 가방 챙기기 추가 |
| 3 | 조용히 문 열기 추가 |
| 4 | 열쇠 수색과 잠금 해제 |
| 5 | 책상 복귀로 지속 추적 해제 |
| 6 | 감시 중 이동하는 교수 시야 |
| 7 | 소음 함정 8곳: 시작 전 3초만 깜빡인 뒤 숨겨짐 |
| 8 | 경로를 예고하고 이동하는 교수 |
| 9 | 경로를 예고하고 왕복하며 감시하는 조교 |
| 10 | 숨겨진 소음 함정·교수 순찰·조용히 문 열기 종합 탈출 |

함정 기억 시간에는 이동, 적의 행동과 제한 시간이 정지합니다. 표시가 사라져도 함정 판정은 유지됩니다. 조교는 오른쪽 통로를 왕복하며 파란 시야로 감시하고, 이동 1초 전에 경로를 표시합니다.

## 모드와 기록

- **일반 모드:** 매번 무작위 패턴, 브라우저에 진행 저장 및 이어하기. 순위 등록 없음.
- **기록 모드:** 단계별 고정 패턴, 서버 검증 후 단계별 TOP 20 등록.
- **오늘의 출튀:** 한국 시간 자정에 갱신되는 공통 패턴과 별도 일일 순위.

동일 브라우저의 단계·모드별 최고점만 반영하며, 닉네임·점수·남은 시간·등록일이 공개됩니다. 브라우저 쿠키를 지우면 새 플레이어로 구분됩니다. 점수는 남은 시간 × 100 + 단계 × 200입니다. 규칙 버전이 다르면 순위를 분리하며 기존 기록은 보존합니다.

## 빠른 실행

Node.js 24 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
```

순위표까지 로컬에서 사용하려면 D1 스키마를 적용합니다.

```sh
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_closed_cargill.sql
npm start
```

DB 없이도 일반 모드는 플레이할 수 있습니다. 순위표·기록 검증에는 Cloudflare Workers/D1을 지원하는 서버 환경이 필요합니다.

## HTML 파일 / 정적 호스팅

```sh
npm run export:standalone
```

생성된 `standalone/index.html` 하나를 브라우저에서 열거나 정적 호스팅에 올릴 수 있습니다. 이 버전은 인터넷 없이 일반 모드로 플레이하며 온라인 순위 등록은 지원하지 않습니다. GitHub에 소스를 올리는 것만으로 Pages나 서버가 자동 배포되지는 않습니다.

## 개발과 검증

```sh
npm test
npm run build
```

`npm test`는 함정 표시와 실제 판정, 준비 시간 정지, 조교 이동·감시, 책상 복귀 회복, 이동 경로, 고정 패턴 클리어 입력 재생, 모드별 기록 분리, 한국 자정 갱신, 기록 검증과 중복 등록 방지를 검사합니다.

- `game/`: 게임 HTML/JS 원본
- `server/rankings.ts`: D1 기록 API와 입력 재생 검증
- `scripts/generate-game.mjs`: 동일 게임 원본에서 서버 검증기와 응답 자산 생성
- `tests/`: 게임·모드·순위 검증 및 클리어 입력
- `db/`, `drizzle/`: 스키마와 마이그레이션
- `.openai/hosting.json`: DB 연결 선언. GitHub 배포본은 운영 사이트 ID를 포함하지 않습니다.

게임 규칙 변경 시 `RULES`를 갱신하고 고정 패턴 입력 fixture를 재검증합니다. 이미 적용한 DB 마이그레이션은 수정하지 않고 새 마이그레이션을 추가합니다. 개발 서버 실행 전에 자산을 자동 생성하며, 빌드/검사 때도 같은 생성기를 사용합니다.

현재 운영 사이트는 Sites의 별도 원격 소스 저장소에서 배포됩니다. 이 GitHub 저장소는 이식 가능한 소스 사본이며 GitHub 변경이 운영 사이트에 자동 적용되지는 않습니다. 로컬 DB·쿠키·인증 정보·빌드 캐시는 업로드하지 않습니다.
